# 未確定事項の一覧

各資料に散らばっている「まだ決めていないこと」を集約したものです。
**いつ決めればよいか**を[取り込み計画の段階](image-editing/04-integration-plan.md#47-取り込みの進め方提案)に対応させています。

## 結論: 進行をブロックするものは実質ありません

第 1 段階（macOS ターゲット化 / 輪郭ロジックの移植 / `CanvasElement` の画像対応）は、
**下記の未確定事項を 1 つも必要としません。** いま着手できます。

理由は 2 つです。

- `MemoRepository` の protocol が切られており、**永続化の細部は後から差し替えられる**
- [クラッシュアンドビルド方針](product/mvp.md#開発方針)なので、決め打ちで進めて後から変えてよい

**MVP をブロックしているのは「決定」ではなく「実装」です。**
特に永続化は、方式が決まった今、あとは書くだけの状態です。

## 補足

### 1. 保存場所 — 実質決着しています

[ホットキーで呼び出して使う](product/hotkeys.md)と決まった時点で、
**ライブラリ管理型**（`~/Library/Application Support/qool/`）以外の選択肢は実質ありません。
「思いついた瞬間に開く」体験に、保存先を選ぶ操作は入りません。

唯一これが骨格に効く判断なので一覧の先頭に置いていますが、**確認するだけの項目**です。

### 3. スキーマバージョン — 最初は 1 行で足ります

JSON に `"schemaVersion": 1` を入れておくだけで、第 1 段階は十分です。
マイグレーションの仕組みは、**実際に 2 回目のスキーマ変更が来たときに考えれば間に合います。**
それ以前は[クラッシュアンドビルド方針](product/mvp.md#開発方針)で消してやり直せます。

### 5. `.qool` — 後から足せます

[レイアウトが「1 メモ = 1 ディレクトリ」](architecture/persistence.md#レイアウト案)なので、
導入はディレクトリ名に拡張子を付けて UTI を宣言するだけです。
**内部構造を変えずに後付けできる**ため、急ぎません。

### 8. プレフィックスの初期値 — 設定可能なので後から変わります

ユーザーが変更できる仕様なので、初期値は決め打ちで進めて問題ありません。
`⌃Q` がターミナルのフロー制御と衝突する件は、**設定画面で変更できることを示せば実害を回避できます。**

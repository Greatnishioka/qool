# 1. 切り抜きフロー（なぞり → 候補抽出 → 選択）

StarWindow のメイン画面 `MemoPaperView` が担当する部分で、
qool の[画像切り抜き画面](../features/03-image-cutout.md)に相当します。

## 画面構成

```text
┌──────────────────────────────────────────────────┐
│ [画像を選択][本文クリア][輪郭をなぞる][被写体抽出]  │ ← ツールバー（横スクロール）
│ [輪郭リセット][メモ化]                             │
├──────────────────────────────────────────────────┤
│ 候補  ★被写体 3.2  前処理 2.8  背景差分 2.1  手描き │ ← 候補選択バー（候補があるときだけ）
├──────────────────────────────────────────────────┤
│                                                  │
│          画像 + 本文 TextEditor                    │
│          + 輪郭オーバーレイ（点線）                 │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 1. 画像を読み込む

- ツールバーの「画像を選択」（`NSOpenPanel`、`allowedContentTypes = [.image]`）
- またはウィンドウへのドラッグ&ドロップ（`.fileURL` と `.image` の両方を受け付け）
- ドロップ中は破線の枠がハイライトされる
- 読み込むと `resetContour()` が走り、なぞり・輪郭・候補はすべて初期化される

画像は `Image(nsImage:).scaledToFit()` で aspect-fit 表示され、
その表示矩形 (`imageRect`) を基準に正規化座標へ変換します。

## 2. 本文を入力する

画像の上に重ねた `TextEditor`（24pt / rounded）で本文を入力します。
なぞり中は `disabled` になります。この本文が最終的なメモの中身になります。

## 3. 外周をなぞる

「輪郭をなぞる」でなぞりモードに入ります。

- 画像上をドラッグすると `tracePoints` に点が追加される（`DragGesture(minimumDistance: 0)`）
- 画像表示矩形の外の座標は無視される
- **前の点から 0.006（正規化距離）以下しか動いていない点は間引く**
- なぞり中は画像に黒 6% のオーバーレイがかかり、青い線と点、操作ヒントが表示される
- 3 点未満だと「被写体抽出」は押せない

なぞりは **正確になぞる必要はなく、対象を大まかに囲むガイド** として使われます。
以降の抽出器はこのガイドの内外の情報を手がかりに輪郭を探します。

## 4. 被写体抽出

「被写体抽出」で `applyTrace()` が実行され、以下が順に走ります。

1. `roughContour = tracePoints` を保存（候補が出なかったときの下地）
2. **7 種類の抽出器を順に実行**して `[ContourCandidate]` を集める（[詳細](02-contour-extractors.md)）
3. `ContourCandidateSelector.scoredCandidates` で各候補をスコアリング
4. `AppDefaults.minimumAutoCandidateScore`（2.05）以上で最高得点のものを **推奨候補**にする
5. 候補ごとに、必要なら `ContourSmoother.polished()` で整形
6. 候補一覧を「推奨 → スコア降順 → 元の順」でソート
7. 末尾に必ず **「手描き」候補**（なぞり線を densify + polished したもの）を追加
   - 推奨候補が 1 つも閾値を超えなかった場合は、この手描きが推奨になる
8. 推奨候補（なければ先頭）を自動選択し、なぞりモードを抜ける

デバッグ設定 `AppDefaults.contourDebugLogging` / `contourDebugImageExport` が有効だと、
候補ごとのスコアと形状指標がコンソールに出力され、`debug-contours/` にオーバーレイ PNG が書き出されます。

## 5. 候補を選び直す

候補選択バーはスコア付きのチップの並びです。

- 推奨候補には ★ が付く
- チップにはソース名（被写体 / 前処理 / 背景差分 / 線色 / 色矩形 / 矩形補正 / Vision / 手描き）とスコア
- ホバーで各ソースの説明がツールチップ表示される
- クリックすると `appliedContour` が差し替わり、画像上の点線が更新される

**この「複数の抽出結果を並べて人間が選ぶ」形が、単一アルゴリズムに頼らないための中心的な設計です。**
入力画像の性質（写真の被写体 / 白い紙 / 色付き付箋 / 枠線のあるメモ）によって
どの抽出器が当たるかが変わるため、自動選択が外れても 1 クリックで直せるようにしています。

## 6. メモ化

「メモ化」で `MemoCreationPreviewSheet` をシート表示します（[調整画面](03-adjustment-editor.md)）。
`appliedContour` が確定していないと押せません。

## 状態

`MemoPaperView` が `@State` で持つ主なもの。

| 状態 | 意味 |
|------|------|
| `memoImage` | 読み込んだ画像 |
| `memoText` | 本文 |
| `tracePoints` | なぞった点（正規化） |
| `roughContour` | なぞり結果の保存 |
| `appliedContour` | 現在採用している輪郭 |
| `contourSelectionCandidates` | 候補一覧 |
| `selectedContourCandidateID` | 選択中の候補 |
| `memoPreviewConfiguration` | 調整画面と共有する設定 |
